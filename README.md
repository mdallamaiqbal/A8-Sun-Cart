🌞 SunCart – E-commerce Platform

SunCart is a modern summer-themed eCommerce platform where users can explore and purchase seasonal products like sunglasses, summer outfits, skincare items, beach accessories, and more.

Users can browse products, view detailed information, and place orders securely after authentication.

🚀 Features
🛍️ Browse seasonal summer products
🔍 View detailed product pages
🔐 Secure authentication (login/register)
👤 User profile management
🛒 Add to cart & checkout system
🏷️ Top brands & category-based browsing
📱 Fully responsive UI (mobile-first design)
⚡ Fast and modern user experience
🧩 Tech Stack
Frontend: Next.js, React
Styling: Tailwind CSS
Authentication: Better Auth / Auth Client
State Management: React Hooks
Notifications: React Hot Toast
🎨 UI Theme

SunCart is designed with a fresh summer vibe:

🩵 Primary Color: #34B0BD (Ocean Blue)
🧡 Secondary Color: #F09633 (Sun Orange)
🌴 Clean, bright, and seasonal UI style
